Eyebrow from @duovino/design-system. Use via `window.DuoVino.Eyebrow` (bundle loaded from the root `_ds_bundle.js`).

A small uppercase label that sits above a heading, giving sections a
refined editorial kicker.

## Props

```ts
interface EyebrowProps {
  children: React.ReactNode;
}
```

## Examples

### Default

```jsx
() => <Eyebrow>Mastery</Eyebrow>
```
